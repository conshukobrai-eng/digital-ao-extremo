🌸 Rede Lilás

Não é só agressão. É sobre vidas. A agressão contra a mulher não começa com um tapa. Ela começa com o controle, com o silêncio imposto, com o medo de ser quem se é. Começa quando uma mulher deixa de se reconhecer. Este espaço foi criado para romper esse silêncio. Aqui, a informação é acolhimento, a orientação é força e a denúncia é um caminho para a liberdade. Nosso compromisso é dar voz a quem por muito tempo foi calada, oferecer apoio, conhecimento e uma rede de proteção para que nenhuma mulher se sinta sozinha. Se você está passando por isso, saiba: a culpa nunca é sua. E você não está sozinha. Informar para proteger. Acolher para transformar. Denunciar para salvar.
